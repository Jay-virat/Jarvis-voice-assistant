
# JARVIS - Voice Controlled Virtual Assistant 🧠🎤

Welcome to **JARVIS**, your personal voice-controlled virtual assistant built using **HTML**, **CSS**, and **JavaScript**! This assistant can recognize your voice commands and respond with actions like opening websites, telling the time/date, making jokes, and more.

---

## 🚀 Features

- 🎙️ Voice command activation
- 🕓 Tells time and date
- 🔍 Google & Wikipedia search integration
- 🎵 Plays music, opens YouTube, Facebook, Instagram
- 🤖 Custom responses like jokes, tips, greetings
- 🏫 Opens Akshaya Institute website
- 🔢 Launches calculator
- 💬 Text-to-speech responses

## 🧠 How to Use

1. Clone or download this repository
2. Open `index.html` in your browser
3. Click the **mic button** and give a command like:
   - “open google”
   - “what is JavaScript”
   - “play believer song”
   - “what’s the time”

> Make sure your browser supports the **Web Speech API** (Chrome recommended).
